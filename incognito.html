Clean a payslip

Use this before you attach a payslip to the airline form. The original stays in this browser. Attach the download, not the original.

Type the values that are yours. The page finds them and, once you tick a line, replaces that value with a placeholder. Labels such as National Insurance stay, so the layout is still readable. A picture of a payslip, with no text layer, cannot be cleaned here.

The values you type are not uploaded. After the file is rebuilt, this page can send that cleaned PDF to incognito.jetwages.com to look for a leftover National Insurance number, email, or sort code. That check is not kept. Pay figures can remain in the cleaned file.

1. Choose the payslip

2. Values to remove

Leave a box empty if it is not on this payslip. Each value needs at least two characters.

3. Lines to replace

Nothing is replaced until you tick it. Lines you typed start ticked. Suggested National Insurance numbers, emails, and sort codes stay unticked until you confirm them.
